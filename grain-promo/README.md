# Промо-ролик Grain

Исходники видео-презентации (16:9, ~30 с, стиль «Ночное небо»).

- `build.cjs` — сценарий и вёрстка ролика: удары под фразы озвучки, кадрирование интерфейса, три направления стиля (`node build.cjs a|b|c`).
- `vo/marks.json` — время фраз озвучки. Текст:
  «Это Грэйн. Плеер для Спотифая. / Вместо списка — живой проигрыватель. / Пластинка крутится, а тонарм идёт к центру вместе с песней. / Перемотка — по кругу, громкость — ручкой. / Альбомы лежат в конвертах, треки — как на обороте пластинки. / Текст песни загорается по словам. / А зимой — снег, гирлянда и сугроб, который растёт, пока ты слушаешь. / Грэйн. Музыка, которую видно.»
- `tools/tts.py` — синтез озвучки (Piper, голос ru-irinia-medium).
- `tools/record-ui.cjs` — запись реального интерфейса Grain в демо-режиме через Playwright.

Записи экрана, звук и рендеры в репозиторий не кладутся (см. `.gitignore`).

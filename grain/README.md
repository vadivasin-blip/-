# Grain

Десктопный плеер для библиотеки Spotify под Windows, устроенный как проигрыватель винила.
Из Spotify берётся только музыка и данные, интерфейс свой.

**Фишка — дека.** Слева всегда стоит вертушка: обложка текущего трека — это «яблоко» пластинки,
пластинка крутится только во время музыки, тонарм по ходу трека смещается к центру, как на настоящем
проигрывателе. Перемотка — по кольцу вокруг пластинки, громкость — поворотная ручка. Плейлисты и альбомы
лежат на «полке» конвертами: при наведении пластинка выезжает из конверта, исполнители — picture disc.
Списки треков оформлены как оборот конверта: точки до длительности, у альбомов — стороны A/B и нумерация A1, B2.

**Новогодняя тема** (по умолчанию; можно включать автоматически с 1 декабря по 14 января):
- снег на canvas: на паузе снежинки почти замирают, ветер от движения мыши, клик выбивает облачко снега, есть «метель»;
- гирлянда под верхней панелью: огни бегут во время музыки и ровно светятся на паузе;
- сугроб внизу окна растёт, пока вы слушаете, клик — разгрести;
- отсчёт до Нового года в верхней панели и салют в полночь (его можно запустить из настроек или палитры: «Салют»);
- ночная палитра, золотой ободок у пластинки, звёзды над декой.

## Обложки

Все обложки, фото исполнителей и картинки плейлистов приходят из Spotify Web API (поле `images`).
Сам Grain рисует только обложки демо-режима (выдуманные исполнители, помечено «демо-данные» в верхней панели)
и обложку «Любимых треков».

## Что умеет

- **Играет прямо в приложении** через Spotify Web Playback SDK: Grain становится отдельным устройством Spotify Connect.
  Если встроенный плеер недоступен, Grain управляет любым другим вашим устройством: телефоном, колонкой, Spotify на ПК.
- **Полка**: плейлисты, любимые треки, сохранённые альбомы, подписки на исполнителей. Можно создавать плейлисты и добавлять или убирать треки.
- **Списки треков**: фильтр (Ctrl+F), сортировка по названию, исполнителю, альбому, дате и длительности, навигация стрелками,
  Enter — играть, Q — в очередь, L — нравится, правый клик — меню.
- **Тексты песен** (LRCLIB): синхронные строки, клик по строке перематывает, есть ручная подстройка синхронизации для каждого трека.
- **Экран «Сейчас играет»** (F): большая вертушка и крупный текст, полноэкранный режим.
- **Мини-плеер** (Ctrl+M): маленькое окно с крутящейся пластинкой поверх всех окон.
- **Палитра команд** (Ctrl+K): поиск по Spotify, вашим плейлистам и действиям из одного поля.
- **Очередь**, **выбор устройства**, **таймер сна** (на N минут или до конца трека).
- **Итоги**: топ исполнителей и треков за 4 недели, 6 месяцев и всё время, жанры, десятилетия, недавние прослушивания.
- **Интеграция с Windows**: медиаклавиши и системный оверлей громкости (SMTC), кнопки ⏮ ⏯ ⏭ на миниатюре в панели задач,
  прогресс трека на значке, трей, глобальные хоткеи Ctrl+Alt+Пробел / ← / → / ↑ / ↓ / L, уведомления о смене трека.

## Первый запуск

Spotify не даёт сторонним плеерам общий ключ, поэтому нужен свой (бесплатно, один раз):

1. Откройте https://developer.spotify.com/dashboard → **Create app**.
2. **Redirect URI**: `http://127.0.0.1:43117/callback`
3. **APIs used**: Web API и Web Playback SDK.
4. Скопируйте **Client ID** в окно входа Grain → «Войти через Spotify».

Требования Spotify: аккаунт **Premium** (для управления воспроизведением и встроенного плеера). Приложение в режиме
разработки работает для владельца и до 5 добавленных пользователей (User Management в настройках приложения).

## Сборка

```bash
npm install
npm start            # собрать интерфейс и запустить
npm run dist:win     # на Windows: release/Grain-Setup-*.exe и Grain-*-portable.exe
npm run dist:win:linux   # то же на Linux (нужны wine и wine32)
```

Демо-режим без аккаунта: на экране входа ссылка «Посмотреть интерфейс на демо-данных».

GitHub Actions (`.github/workflows/grain-windows.yml`) собирает exe на `windows-latest` при каждом изменении в `grain/`.
Готовые файлы лежат в артефакте `Grain-Windows`.

### Встроенный плеер и Widevine

Музыка Spotify защищена DRM, поэтому Grain собран на [castLabs Electron](https://github.com/castlabs/electron-releases)
с Widevine. Модуль Widevine скачивается при первом запуске. Если Spotify откажется проигрывать в самом Grain
(в настройках будет красная точка у «Встроенный плеер»), включите Spotify на ПК или телефоне: Grain будет им управлять.
Чтобы встроенный плеер работал в любом случае, сборку можно подписать VMP через castLabs EVS
(бесплатный аккаунт, `pip install castlabs-evs`) и собрать с `EVS_SIGN=1`.

## Устройство кода

```
electron/main.cjs     окно без рамки, локальный сервер 127.0.0.1:43117 (интерфейс + OAuth-колбэк),
                      трей, кнопки на панели задач, мини-режим, глобальные хоткеи, токены через safeStorage
src/lib/spotify.ts    Web API с учётом изменений Spotify 2026 (/me/library, /playlists/{id}/items) и откатом на старые пути
src/lib/player.ts     встроенный плеер (SDK) + синхронизация с /me/player, команды, лайки, таймер сна
src/lib/lyrics.ts     тексты LRCLIB, разбор LRC, кэш, сдвиги синхронизации
src/views, src/components   экраны и компоненты на React
```
